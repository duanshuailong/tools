# ISO 制作操作步骤（SOP）

> 目标：把原版 Ubuntu Server 24.04 ISO + 离线包 + 驱动，打包成可无人值守装机的 `new-ubuntu.iso`。
> 环境：**采集机**（纯净 Ubuntu 24.04，同架构）负责下载离线包；**制作机**（有 xorriso）负责打包。二者可为同一台。
> 目录结构 / 包清单 / 版本对齐 / 原理详解见 [`README.md`](./README.md)。

占位符：`<...>` 表示按实际替换。

---

## 前置检查

- [ ] 采集机 = 目标 ISO 同版本（`lsb_release -a` 为 24.04）、同架构、**系统纯净**
- [ ] 制作机已装 `xorriso`（`xorriso --version`）
- [ ] 磁盘余量 ≥ **20 GB**（解包 + 拷贝 cuda.run 需要）
- [ ] 已下载原版 `ubuntu-24.04.x-live-server-amd64.iso`

---

## 步骤 1：准备工作目录

把服务器侧内容同步到本目录，最终形态：

```
template/
├── ubuntu-<版本>-live-server-amd64.iso   ← 放入原版 ISO
├── pack.sh
├── debs/            ← 同步（含各子目录的 package 文件 + gen_packages.sh）
└── drivers/
    └── cuda_<版本>_linux.run             ← 放入完整 CUDA 包（勿手动拆分）
```

```bash
cd <本 template 目录>
ls ubuntu-*.iso            # 确认原版 ISO 就位（pack.sh 用 ls|grep ^ubuntu.*iso$ 匹配）
ls drivers/cuda_*run       # 确认 CUDA 完整包就位
ls debs/*/package | head   # 确认各目录 package 清单已同步
```

---

## 步骤 2：采集离线 deb 包 + 生成索引

> 若 `debs/` 已由服务器侧同步好现成 `.deb`，可跳过 2a/2b/2c 采集，直接到 2d 生成索引。

### 2a. 手动采集离线包

在采集机（纯净 24.04）上分组执行（命令全文见 README.md 第 4 章）：

```bash
cd /var/cache/apt/archives
# ① 通用包
apt install --download-only build-essential make gcc ... docker.io chrony
# ② 内核专属（必须在 24.04 上跑，自动取 6.8.0-111）
apt install --download-only linux-tools-$(uname -r)
# ③ 运维补充、④ OFED 编译依赖、⑤ 其他补充……
```

采集后按用途拆进 `debs/<子目录>/`，目录名须与 `user-data` 里 `dpkg -i /cdrom/debs/<目录>/*.deb` 路径一致。

### 2c. nvidia-container-toolkit（必做：Docker 跑 GPU，需先加 NVIDIA 容器源）

不在 Ubuntu 官方源，**采集前必须先执行以下 3 步加源**（对应现网命令 68/69/70）：

```bash
# ① 装加源前置工具
sudo apt-get update && sudo apt-get install -y --no-install-recommends ca-certificates curl gnupg2
# ② 导入 GPG key + 写入 source list
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey \
  | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg
curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list \
  | sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' \
  | sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list
# ③ 刷新索引
sudo apt update
# ④ 仅下载指定版本（版本号按实际替换，需与其余组件/驱动策略一致）
export NVIDIA_CONTAINER_TOOLKIT_VERSION=<1.19.0-1>
sudo apt-get install --download-only -y \
    nvidia-container-toolkit=${NVIDIA_CONTAINER_TOOLKIT_VERSION} \
    nvidia-container-toolkit-base=${NVIDIA_CONTAINER_TOOLKIT_VERSION} \
    libnvidia-container-tools=${NVIDIA_CONTAINER_TOOLKIT_VERSION} \
    libnvidia-container1=${NVIDIA_CONTAINER_TOOLKIT_VERSION}
# ⑤ 从缓存归档到 debs/base/（或 debs/nvidia/）
#   cp /var/cache/apt/archives/{nvidia-container-toolkit,libnvidia-container}*.deb debs/base/
```

> 版本号用 `apt-cache madison nvidia-container-toolkit` 查可用版本；四个包版本必须一致。
> 当前基准为 `1.19.0-1`（与 NVIDIA 驱动版本无关，可独立选定）。

### 2d. 生成离线 APT 仓库索引

所有 deb 归档到位后，在 `debs/` 下生成索引（`debs/gen_packages.sh` 内容）：

```bash
cd debs
bash gen_packages.sh
# 等价于：
#   dpkg-scanpackages -m . /dev/null > Packages
#   dpkg-scanpackages -m . /dev/null | gzip -9c > Packages.gz
```

生成 `Packages`/`Packages.gz` 后，`debs/` 即成离线 APT 源，装机可加 `deb [trusted=yes] file:///cdrom/debs ./` 自动解析依赖。

## 步骤 3：放置驱动 + 版本对齐检查

```bash
ls -l drivers/cuda_*run    # 完整 CUDA 包（>4GB，未拆）
```

**对齐检查（三段号必须一致，否则 fabricmanager 不起）**：

| 项 | 命令 / 位置 | 期望 |
|----|------------|------|
| 驱动版本 | `drivers/cuda_*_<驱动版本>_linux.run` 文件名 | `<驱动版本>` |
| fabricmanager | `ls debs/nvidia/*fabricmanager*` | = 驱动版本 |
| nscq | `ls debs/dcgm-*/*nscq*` | = 驱动版本 ⚠ 当前仍 580，需升 595.71.05 |

- [ ] 驱动 = fabricmanager(运行时) = nscq 三段号一致（当前基准 595.71.05）
- [ ] ⚠ 确认 `debs/nvidia/` 有**运行时** `nvidia-fabricmanager`（不只是 `-dev`），否则服务装不出
- [ ] 如整体升版本，目录名 `dcgm-580`→`dcgm-<新>` 并同步改 `user-data` 中对应路径

---

## 步骤 4：打包

```bash
cd <本 template 目录>
bash pack.sh
# 精简版（不含 NVIDIA/OFED）：
# INCLUDE_NVIDIA=no INCLUDE_OFED=no bash pack.sh
```

pack.sh 会：解包原 ISO → 拷入 `debs/`+`drivers/` → 追加 `md5sum.txt` → `split` 拆分 CUDA → `xorriso replay` 重封装 → 输出 `new-ubuntu.iso`。

预期结尾：`Done: <路径>/new-ubuntu.iso`

---

## 步骤 5：验证产物

```bash
file new-ubuntu.iso                              # 含 (bootable)
xorriso -indev new-ubuntu.iso -lsl /drivers      # cuda_*.run + cuda_*.run_a 两段
xorriso -indev new-ubuntu.iso -find /debs/nvidia # 包已注入
```

---

## 步骤 6：装机（提供 autoinstall）

1. 用 `new-ubuntu.iso` 引导目标机（IPMI 挂载 / U 盘）。
2. 提供机型 autoinstall（nocloud）：`QY-B300-IB/`（含 `user-data`、`meta-data`）。
3. 装机自动完成：读 BMC IP 定主机名 → 自动选盘 + RAID1 → 离线装包/驱动 → 重启。

### 装机后验证

```bash
nvidia-smi | head                        # Driver 版本正确
systemctl status nvidia-fabricmanager    # active (running)
nvidia-smi -q | grep -i fabric           # Fabric State: Completed
cat /proc/mdstat                         # RAID1 md0/md1 正常
```

## 附：常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| `fabricmanager version does not match` | FM≠驱动 | 步骤 3 对齐三段号 |
| DCGM 查不到 NVSwitch | nscq 版本不符 | 升 nscq 到驱动版本 |
| `Unable to locate package libfuse2t64` | 采集机是 22.04 | 22.04 用 `libfuse2` |
| 封装后不能引导 | 未用 replay | 保持 pack.sh 原方式 |
| 磁盘不足 | cuda.run 解包占空间 | 清理 `*.old.*`，留 ≥20GB |
